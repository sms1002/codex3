# 학교 프로젝트 설명 자료

## 한 문장 설명

CSV 데이터와 사용자의 한국어 질문을 입력받아, 오프라인 지도학습 모델이 통계 분석 방법을 추천하고 계산된 결과를 그래프와 쉬운 한국어 문장으로 설명하는 Windows 프로그램입니다.

## 무엇이 AI인가

질문 문장 56개에 `기술통계`, `두 집단 비교`, `상관분석` 등 정답 라벨을 붙여 학습 자료로 사용했습니다. 앱은 문장을 단어·글자 조각으로 나누고, 각 분석 방법에서 그 조각이 얼마나 자주 나타났는지 학습하는 **다항 나이브 베이즈 분류기**를 사용합니다. 처음 보는 질문이 들어오면 학습한 패턴과 비교해 분석 방법을 추천합니다.

이 모델은 대규모 언어 모델이나 채팅봇이 아닙니다. 변수의 의미와 통계 가정을 완전히 이해하지 못하므로 날짜·코드·상수 열을 걸러내는 검사와 사용자 확인 단계를 따로 둡니다. 계산 결과의 한국어 설명은 투명한 규칙 기반이며 AI가 생성한 문장이 아닙니다.

## 데이터 과학 부분

CSV 인코딩·빈칸·중복·이상치를 살펴보고, 데이터의 한 행과 한 열이 무엇을 의미하는지 확인합니다. 질문에 맞는 변수와 분석 방법을 선택합니다. 통계 엔진의 계산은 SciPy와 비교했고, 보고서의 p-value·효과 크기·주의 사항을 함께 읽도록 설계했습니다. 상관관계만으로 원인을 단정하거나, 시계열 데이터를 독립적인 표본처럼 해석하지 않도록 안내합니다.

## 발표 시 보여줄 흐름

1. 학생 예제 CSV를 열고 `공부시간으로 시험점수를 예측하고 싶어`라고 입력합니다.
2. AI가 **선형회귀**를 후보로 제안하고 공부시간·시험점수를 고르는 모습을 보여줍니다.
3. 실행 후 기울기, 설명력, p-value의 쉬운 뜻과 그래프를 확인합니다.
4. `성별과 학년이 관련 있는가`를 입력해 **카이제곱** 후보가 나오는 것을 보여줍니다.
5. 데이터에 필요한 그룹 열이 없으면 AI가 분석을 강행하지 않고 부족한 조건을 알려주는 예를 보여줍니다.

## 검증과 한계

학습에 넣지 않은 질문 14개를 별도로 분류해 14개가 예상 방법과 일치했습니다. 이 숫자는 작은 내부 시험의 결과일 뿐 전체 사용자 질문에서 100% 맞는다는 뜻은 아닙니다. 통계 엔진은 SciPy 대조 61개 사례, 수치 비교 193개를 통과했습니다. 실제 Electron 화면 테스트에는 AI 추천과 보고서 저장이 포함됩니다.

## 팀 활동 기록에 쓸 때

AI 분야에서는 학습 문장 설계, 특징 추출, 나이브 베이즈 구현, 별도 질문 평가와 실패 사례 개선을 설명할 수 있습니다. 데이터 과학 분야에서는 데이터 구조 확인, 분석 방법의 적합성 판단, 수치 검증, 결과 해석과 한계 설명을 다룰 수 있습니다. **각 학생이 실제로 수행하고 이해한 일만** 개인 활동으로 기록해야 합니다.
