# StatPilot · AI 통계 분석 도우미 1.2.1

**프로젝트 주제:** AI를 활용한 데이터 기반 통계 분석 방법 자동 선택 및 결과 해석 시스템 개발

Windows에서 인터넷 없이 CSV를 살펴보고 통계 분석을 하는 무료 앱입니다. 사용자가 궁금한 점을 한국어 문장으로 쓰면 작은 **지도학습 문장 분류 모델**이 7가지 분석 방법 중 후보를 추천합니다. 열의 종류와 개수는 별도 검사를 거쳐 가능한 변수만 제안합니다. 그래프와 결과 설명은 실제 통계 계산값에 따른 규칙 기반 문장입니다. 생성형 AI나 유료 API는 사용하지 않습니다.

## 실행

`release/AI-Stat-Desktop-1.2.1/AI-Stat-Desktop.exe`를 실행합니다. 다른 Windows PC에서는 `release/AI-Stat-Desktop-Windows-x64-v1.2.1.zip`을 **전체 압축 해제**하고 그 안의 실행 파일을 엽니다. ZIP 안의 DLL과 `resources` 폴더를 함께 두어야 합니다. Python·Node.js·AI 모델을 따로 설치할 필요는 없습니다.

1.2.1에서는 앱 화면과 그래프를 글자가 잘 보이는 밝은 색으로 바꿨습니다. 통계 계산과 AI 추천 방식은 1.2.0과 같습니다.

## 처음 쓰는 사람을 위한 순서

1. **CSV 파일 불러오기**에서 UTF-8 또는 CP949 파일을 선택합니다. 한 행이 사람·날짜·지역 중 무엇인지 먼저 확인합니다.
2. **궁금한 점을 한 문장으로** 적고 **AI로 방법 찾기**를 누릅니다. 예: `공부시간으로 시험점수를 예측하고 싶어`, `평균기온의 분포와 중앙값을 보고 싶어`.
3. AI 후보의 분석 방법과 변수 선택이 실제 질문에 맞는지 확인하고 **통계 분석 실행**을 누릅니다. 필요한 그룹·숫자 열이 없으면 자동 분석하지 않고 이유를 알립니다. 직접 방법을 고를 수도 있습니다.
4. 결과 숫자 아래의 **화면의 숫자 뜻**, 그래프, 해석, **확인 사항**을 읽습니다. **분석 보고서 저장**으로 그래프를 포함한 HTML을 저장할 수 있습니다.
5. 빈칸·이상치를 처리해야 할 근거가 있을 때만 **데이터 정리**를 실행합니다. 기본은 원본을 그대로 두는 설정이며, 전처리 후에는 분석 데이터를 전처리본으로 바꿔 다시 계산할 수 있습니다.

지원 분석은 기술통계, Welch 독립 두 집단 t검정, 일원분산분석, Pearson·Spearman 상관, 단순 선형회귀, 카이제곱 독립성 검정입니다. 분석에 필요한 값이 빈 행만 해당 분석에서 제외합니다. 시계열의 인접 기록이나 같은 사람의 반복 측정처럼 독립성이 없는 자료는 검정의 p-value를 그대로 해석하기 어렵습니다.

## AI 기능의 실제 범위

- `src/ai-recommender.js`는 7개 분석 목적마다 8문장씩, **56개의 검토된 한국어 질문 예시**를 학습합니다. 단어와 글자 조각을 특징으로 추출하고 **다항 나이브 베이즈** 점수로 질문을 분류합니다. 앱 시작 시 PC에서 학습·추론하며 네트워크 요청은 없습니다.
- 모델은 **질문의 의도에 맞는 분석 방법 후보**를 고릅니다. 변수의 의미를 이해하거나 연구 설계의 타당성을 판단하는 생성형 모델은 아닙니다. 변수 선택은 이름 일치, 숫자·분류 여부, 고유값 수 같은 명시적 기준으로 검사합니다. 날짜·지점 코드·ID 및 값이 하나뿐인 열은 자동 후보에서 제외합니다.
- 학습 문장과 별도로 작성한 질문 **14개 중 14개**를 `tests/ai.test.js`에서 맞혔습니다. 작은 내부 검증이며 새로운 표현·분야 전체에서의 정확도를 보증하지 않습니다. 모호한 질문은 사용자가 다시 쓰거나 직접 방법을 골라야 합니다.
- 통계값은 `src/analysis.js`에서 계산합니다. 한국어 해석과 그래프는 `src/analysis-ui.js`에서 계산 결과에 따른 규칙으로 만듭니다. AI가 통계값이나 보고서 수치를 지어내지 않습니다.

학교 프로젝트 설명과 팀 역할 제안은 [AI_PROJECT_NOTES.md](AI_PROJECT_NOTES.md)에 정리했습니다. 실제 수행하지 않은 역할은 활동 기록에 적지 마세요.

## 개발 및 검증

개발 PC에는 Node.js 20 이상과 프로젝트 의존성이 필요합니다.

```powershell
node tests/analysis.test.js
node tests/ai.test.js
python tests/compare_scipy.py node
./node_modules/electron/dist/electron.exe tests/smoke.js
```

화면 테스트는 실제 Electron 창에서 AI 추천·변수 선택·추천 불가 안내, 7가지 통계 분석, 보고서와 CSV 저장, 데이터 전환과 오류 처리를 검증합니다. SciPy 대조는 통계 계산의 개발 검증용이며 앱 실행에는 필요하지 않습니다. 결과 이미지는 `tests/artifacts/`에 생성됩니다.

## Windows 배포본 만들기

```powershell
./node_modules/.bin/electron-builder.CMD --win dir --x64
```

생성된 `dist/win-unpacked` 전체를 버전별 `release` 폴더에 담고 ZIP으로 묶습니다. `release`는 Git에서 제외되므로 실행 파일과 ZIP은 GitHub Release에 별도 첨부합니다. 이전 Python 버전의 `app.py`와 `modules/`는 이 데스크톱 앱 실행에 사용되지 않습니다.
